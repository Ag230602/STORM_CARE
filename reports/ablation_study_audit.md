# Ablation Study Audit

## Root Causes
- The previous ablation script wrote dash placeholders and hardcoded full-model values.
- Static-graph and no-transport variants were trained with damage-only MSE, so they did not evaluate the humanitarian heads requested in the table.
- Runtime was not recorded in several earlier module logs, so targeted runtime reruns were added for the no-physics and no-world-model cost cells.

## Fixes
- `scripts/run_ablations.py` now regenerates Table 3 from sourced metrics and reruns Module 3 graph ablations on the same train/test seeds.
- The no-SSL foundation row is evaluated as a random-initialization model on the same validation windows as the selected pretrained checkpoint.
- No-physics and no-world-model computational costs are measured by fresh runtime-only reruns and saved under `metrics/ablations/`.
- Non-applicable cells are filled with explicit status values so the table has no hidden blanks or fabricated numbers.

## Validity Notes
- Metrics are only compared within the evaluator named by the units/protocol columns.
- Physics ablation supports physical-consistency comparisons; it does not supply humanitarian-head metrics.
- Graph-edge ablations support humanitarian-head comparisons; they do not supply foundation forecast calibration.
- Counterfactual world-model ablation remains documented by the counterfactual audit outputs, not by forced forecast-table metrics.
